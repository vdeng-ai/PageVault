# Configuration

PageVault uses environment values for authentication, host routing, expiry defaults, upload limits, and runtime storage paths. Keep real credentials in ignored environment files or your deployment platform's secret store.

The product name is `PageVault`; deployment identifiers, package scopes, and data paths use the lowercase `pagevault` form.

## Shared Application Settings

| Name                       | Required              | Default                                    | Description                                                           |
| -------------------------- | --------------------- | ------------------------------------------ | --------------------------------------------------------------------- |
| `ADMIN_EMAIL`              | Yes                   | None                                       | Email address for the single administrator account.                   |
| `ADMIN_PASSWORD_HASH`      | Yes                   | None                                       | PBKDF2-SHA256 value generated by `pnpm tsx scripts/hash-password.ts`. |
| `SESSION_SECRET`           | Yes                   | None                                       | Long random value used to sign administrator sessions.                |
| `APP_ENV`                  | Cloudflare deployment | `production` in Docker                     | Set to `production` outside a local development environment.          |
| `ADMIN_BASE_URL`           | Cloudflare deployment | `https://admin-html.example.com` in Docker | Full admin origin without a trailing slash.                           |
| `PUBLIC_BASE_URL`          | Cloudflare deployment | `https://h.example.com` in Docker          | Full public origin without a trailing slash.                          |
| `DEFAULT_URL_EXPIRE_DAYS`  | No                    | `7`                                        | Default lifetime of a public URL.                                     |
| `DEFAULT_FILE_EXPIRE_DAYS` | No                    | `180`                                      | Default retention period for an uploaded file.                        |
| `MAX_UPLOAD_SIZE_MB`       | No                    | `10`                                       | Maximum accepted upload size in MiB.                                  |

`ADMIN_BASE_URL` and `PUBLIC_BASE_URL` must use different hostnames in production. PageVault routes requests by the incoming `Host` header, not by a path prefix.

Generate credentials locally and never commit the resulting values:

```bash
pnpm tsx scripts/hash-password.ts
openssl rand -base64 32
```

## Cloudflare Settings

Cloudflare bindings and non-secret tuning values live in `apps/worker/wrangler.jsonc`. Keep the binding names `ASSETS`, `DB`, and `HTML_BUCKET` unless the application code is updated at the same time.

| Name                         | Default    | Description                                                                                                                                                |
| ---------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PUBLIC_HTML_CACHE_SECONDS`  | `3600`     | Maximum Cloudflare cache lifetime for public HTML and rendered Markdown. Effective cache lifetime never exceeds URL or file expiry. Set to `0` to disable. |
| `ACCESS_COUNT_MODE`          | `windowed` | `windowed` batches counters, `exact` writes each access, and `off` disables access counting.                                                               |
| `ACCESS_COUNT_FLUSH_SECONDS` | `300`      | Approximate flush interval for windowed access counters.                                                                                                   |

For local development, Wrangler reads `apps/worker/.env`. Production deployment uses the ignored `apps/worker/.env.production` file through the repository's deploy script. See [Cloudflare Deploy](./cloudflare-deploy.md).

## Docker Settings

| Name                | Required | Default                            | Description                            |
| ------------------- | -------- | ---------------------------------- | -------------------------------------- |
| `SQLITE_PATH`       | No       | `/data/pagevault/pagevault.sqlite` | SQLite database file.                  |
| `LOCAL_STORAGE_DIR` | No       | `/data/pagevault/objects`          | Directory containing uploaded objects. |
| `PORT`              | No       | `3000`                             | HTTP port inside the container.        |

The current Docker image always uses the Node.js runtime, SQLite, and local object storage. The `RUNTIME`, `DB_DRIVER`, and `STORAGE_DRIVER` labels in the example Compose file are descriptive compatibility values, not runtime switches.

Persist and back up both `SQLITE_PATH` and `LOCAL_STORAGE_DIR`. Do not expose either path through the reverse proxy. See [Docker Deploy](./docker-deploy.md).

## Secret Handling

- Do not commit `.env`, `.env.production`, filled Compose files, password hashes, session secrets, or Cloudflare credentials.
- Scope the session cookie to the admin hostname; do not use a parent-domain cookie.
- Rotate `ADMIN_PASSWORD_HASH` to change the login password.
- Rotate `SESSION_SECRET` to invalidate every existing administrator session.
- Keep Cloudflare R2 private and local object files outside the reverse proxy's document root.

See [Security](./security.md) for the complete runtime trust model.
